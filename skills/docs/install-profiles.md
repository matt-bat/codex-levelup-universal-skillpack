# Install Profiles

Use profiles to adopt only the amount of process you need.

## Minimal
For simple local assistance and small edits.

Skills:
1. `token-reduction`
2. `order-of-operations`
3. `scripted-command-execution`
4. `process-budget-controller`

## Developer
For normal software work with validation and documentation.

Includes Minimal plus:
1. `regression-prevention`
2. `effective-testing-methods`
3. `doc-maintenance`
4. `file-maintenance`
5. `diagnose-before-fix`

## Governed
For release-sensitive, policy-heavy, or multi-skill workflows.

Includes Developer plus:
1. `skill-governance`
2. `governance-enforcement`
3. `semantic-policy-audit`
4. `interdependent-change-planning`
5. `user-instructions-tracker`
6. `skill-usage-review`
7. `deprecation-management`

## Frontend
For frontend layout, interaction, and UX work.

Includes Developer plus:
1. `thoughtful-approach`
2. `ui-design-skills`
3. `ui-spatial-canvas`
4. `pseudo-agentic-automation`

## Full
Use the full pack when you want strict continuity, lifecycle management, and governance.

Full includes all skills and all docs in this repository.

## Recommendation
Start with `Developer` unless you are publishing governed policy changes. Move to `Governed` when changes affect skill behavior, CI, validation, release posture, or user instruction tracking.
